## 📁 Estructura del Repositorio

```
Guia-bases-datos-bioinformatica/
├── assets/                     # Recursos externos del repositorio
├── bibliographic-database/     # Bases de datos bibliográficos
│   ├── google-scholar/
│   ├── pubmed/
│   ├── scopus/
│   └── WOS/
├── DNA-database/               # Bases de datos de secuencias de ADN
│   ├── ensembl/
│   ├── genbank/
│   └── refseq/
├── other-database/             # Bases de datos funcionales, metabólicas y clínicas
│   ├── functional-annotation/
│   ├── oncology/
│   └── pathways/
├── protein-database/           # Bases de datos de estructura y secuencia de proteínas
│   ├── interpro/
│   ├── PDB/
│   └── uniprot/
├── RNA-database/               # Bases de datos de expresión y transcriptómica
│   ├── arrayexpress/
│   ├── expression-atlas/
│   └── GEO/
├── CONTRIBUTING.es.md          # Guía de contribución para colaboradores en español
├── CONTRIBUTING.md             # Guía de contribución para colaboradores en inglés
├── LICENSE                     # Licencia
├── README.es.md                # README en español
├── README.md                   # README en inglés
└── TEMPLATE.md                 # Plantilla para contribuciones

```

## 🤝 ¡Contribuye al proyecto!

Este es un **proyecto comunitario** y crece gracias a las aportaciones de la comunidad científica y de desarrollo. Si conoces una base de datos esencial que no está listada, encuentras un enlace caído o quieres mejorar las descripciones:

1. Revisa nuestra [Guía de Contribución](CONTRIBUTING.md) para conocer las pautas de estilo.
2. Abre un **Issue** para proponer cambios o discutir nuevas categorías.
3. Envía un **Pull Request** con tus aportes.

¡Cualquier contribución, por pequeña que sea, es de gran ayuda!
