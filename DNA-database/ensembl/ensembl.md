# 🧬ENSEMBL


🔗**Website:** [ENSEMBL](https://www.ensembl.org/)

## 📌 What is it used for?

Ensembl provides a genome browser that acts as a single point of access to annotated genomes for vertebrate and non vertebrate species. It provides high‑quality, regularly updated genome annotations for humans and hundreds of other species. It integrates multiple layers of biological data making it possible for users to move seamlessly from genome-level views to detailed gene or protein annotations.

## 🗂️ Type of database

| **By data origyn** | **By data review** |
|---|---|
| Secondary | Hybrid |

Maintained jointly by the European Bioinformatics Institute (EMBL‑EBI) and the Wellcome Sanger Institute.

## ⭐ Key features

- Information about genes, transcripts and further annotation can be retrieved at the genome, gene and protein level. 
- Thousands of genomes are included with expanding species coverage.
- It can be used for comparative genomics (homology, gene trees, orthology/paralogy and whole‑genome alignments).
- It is an open access and open-source software database, all data and tools are available to the scientific community for free.
