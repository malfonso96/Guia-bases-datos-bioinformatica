# 🧬 RefSeq - NCBI reference sequences


🔗**Website:** [RefSeq](https://www.ncbi.nlm.nih.gov/refseq/)

## 📌 What is it used for?

RefSeq is a public database of nucleotide and protein sequences with feature and bibliographic annotation. The collection provides a curated, non-redundant, explicitly linked nucleotide and protein database representing significant taxonomic diversity.

## 🗂️ Type of database

| **By data origyn** | **By data review** |
|---|---|
| Secondary | Hybrid |

Built and distributed by the National Center for Biotechnology Information (NCBI), a division of the National Library of Medicine located at the US National Institutes of Health. 
RefSeq is not uniformly reviewed. It includes several status categories, each indicating a different level of curation.

## ⭐ Key features

- RefSeq provides a single, representative sequence for each gene, transcript, or protein.
- Each RefSeq record receives a stable identifier that remains constant across updates, making RefSeq ideal for long-term referencing.
- It includes curated sequences for genomes, mRNA transcripts, proteins, reference genome assemblies and model organisms and clinically relevant species.
- Records are continuously updated.
