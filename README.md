## 📁 Repository Structure

```
Guia-bases-datos-bioinformatica/
├── assets/                     # Repository external resources
├── bibliographic-databases/    # Bibliographic databases
│   ├── google-scholar/
│   ├── pubmed/
│   ├── scopus/
│   └── WOS/
├── DNA-database/               # DNA sequence databases
│   ├── ensembl/
│   ├── genbank/
│   └── refseq/
├── other-database/             # Functional, metabolic, and clinical databases
│   ├── functional-annotation/
│   ├── oncology/
│   └── pathways/
├── protein-database/           # Protein structural and sequence databases
│   ├── interpro/
│   ├── PDB/
│   └── uniprot/
├── RNA-database/               # Expression and transcriptomics databases
│   ├── arrayexpress/

├── CONTRIBUTING.es.md          # Contribution guide for collaborators in Spanish
├── CONTRIBUTING.md             # Contribution guide for collaborators in English
├── LICENSE                     # License
├── README.es.md                # README in Spanish
└── README.md                   # README in English
```

## 🤝 Contributing to the Project

This is a **community project** and it grows thanks to the contributions of the scientific and development community. If you know of an essential database that is not listed, find a broken link, or want to improve the descriptions:

1. Review our [Contribution Guide](CONTRIBUTING.md) to learn about the style guidelines.
2. Open an **Issue** to propose changes or discuss new categories.
3. Submit a **Pull Request** with your contributions.

Every contribution, no matter how small, is a huge help!
