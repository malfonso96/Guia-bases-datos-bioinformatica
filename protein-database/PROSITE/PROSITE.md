# PROSITE

🔗**Website:** [PROSITE](https://prosite.expasy.org/)

## 📌 What is it used for?

PROSITE is a database of protein families, domains and functional sites. It contains conserved sequence patterns and profiles that allow researchers to identify
characteristic regions in protein sequences and predict their possible functions.

It is commonly used to classify proteins into families, identify functional domains and motifs, detect conserved amino acid regions and infer the biological function 
of uncharacterized proteins.

## 🗂️ Type of database

| **By data origyn** | **By data review** |
|---|---|
| Secondary | Reviewed |

Maintained by the SIB Swiss Institute of Bioinformatics (Switzerland). PROSITE entries are manually curated and include documentation describing the biological
function, structure and characteristics of protein families and domains.

## ⭐ Key features

- Protein signatures are represented using different methods:
  - **Patterns:** describe conserved amino acid motifs using a specific sequence pattern.
  - **Profiles:** use position-specific scoring matrices to detect conserved regions, allowing for greater sequence variability.

- Each entry has a unique accession number and associated documentation describing the protein family, domain or functional site.
- ScanProsite allows users to search protein sequences against PROSITE patterns and profiles to identify conserved motifs and domains.
- ProRule provides additional rules to improve functional and structural annotation, identifying amino acids that are critical for protein function.
- PROSITE is integrated into InterPro, which combines information from multiple protein signature databases.
- Data can be downloaded or accessed programmatically through the PROSITE web services.
